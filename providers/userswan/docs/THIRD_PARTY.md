# Third-party software and licensing

This repository contains a patch intended to modify strongSwan source files and a forwarder that links against lwIP.

Before publishing or distributing binaries, review and comply with the licenses of:

- strongSwan and the specific strongSwan source files modified by the patch;
- lwIP;
- OpenSSL/GMP and other libraries selected by your strongSwan build;
- your distribution packages/toolchain.

No license file for the original userswan helper code is imposed by this generated repository. The repository owner should choose and add an explicit license before accepting outside contributions or distributing the original helper code under specific terms. The license chosen for original helper files does not override licenses or obligations that apply to patched upstream code or linked dependencies.
